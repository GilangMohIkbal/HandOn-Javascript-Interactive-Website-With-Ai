# Pendamping Slide Day 16 (PPT)

Latihan ini diambil dari empat cerita latihan dan empat bonus opsional pada **PPT Day 16**. File ini tidak diperlukan untuk menjalankan Product 1 atau Product 2, tetapi berguna untuk memahami `if/else`, `switch`, `for`, `while` melalui Node.js.

Jalankan setiap file dari root repository, contohnya:

```bash
node exercises/day16/latihan1_gratis_ongkir.js
node exercises/day16/latihan2_diskon_bertingkat.js
node exercises/day16/latihan3_kopi_gratis.js
node exercises/day16/latihan4_promo_mingguan.js
node exercises/day16/bonus.js
```

Ini **bukan** aturan checkout dari Day 14, dan bukan bagian dari API produk. Contoh diskon, ongkir, dan kopi hanya untuk latihan control flow.
